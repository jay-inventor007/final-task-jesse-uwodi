## 1. Targeted Roles

### Primary Role: Product Engineer (Mobile & Full-Stack)
- **What this role actually does:** Builds user-facing features end-to-end (mobile interface with React Native, API design, database schemas, and external integrations) with high ownership over user experience and system reliability.
- **Why it fits Jesse:** Extensive track record building solo products from database to UI (e.g. MarkMD, Cognoscope, Supabase/PostgreSQL backends), with direct care for user retention, billing ergonomics, and real production stability.

### Secondary Role: Design Engineer (Figma → React Native / React)
- **What this role actually does:** Bridges the gap between high-fidelity design systems in Figma and pixel-accurate, animated, accessible code in production.
- **Why it fits Jesse:** Visual design background, expertise in design tokens, component architecture (shadcn/ui, Reanimated, gesture handling), and deep attention to micro-interactions.
